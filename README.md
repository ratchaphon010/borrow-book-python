## แอปยืมหนังสือ

## วัตถุประสงค์

เพื่อเพิ่มความสะดวกและรวดเร็วในการทำรายการยืมและคืนหนังสือ  
เพื่อลดข้อผิดพลาดในการตรวจสอบสต็อกหนังสือ สิทธิ์การยืม และการคิดค่าปรับ  
เพื่อให้ระบบสามารถทำงานได้อย่างต่อเนื่องรองรับการทำรายการหลายครั้ง (Looping)

นักศึกษา  
สมาชิกห้องสมุด  

## ฟังก์ชันหลัก

**"1.ฟังก์ชันยืมหนังสือ (Borrow)"**

ตรวจสอบสต็อกหนังสือ และ สิทธิ์การยืม (ไม่เกิน 3 เล่ม)  
บันทึกการยืม ตัดสต็อก และกำหนดวันส่งคืนอัตโนมัติ

**"ฟังก์ชันคืนหนังสือ (Return)"**

รับคืนหนังสือ คืนสต็อกเข้าคลัง และคิดค่าปรับอัตโนมัติหากเกินกำหนด  
## เป้าหมายของระบบ

พัฒนาระบบยืม-คืนหนังสืออัตโนมัติ เพื่อช่วยให้การทำรายการมีความรวดเร็ว แม่นยำ  
ลดข้อผิดพลาดในการตรวจสอบสต็อก สิทธิ์การยืม และการคำนวณค่าปรับเกินกำหนด
